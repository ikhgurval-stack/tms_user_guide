Энэ нь унших, бэлтгэх дараалал. Системийн заавал биелүүлэх хамаарлыг баталсан тохиргооны эх сурвалж байхгүй.

Зааврууд байгууллагын жагсаалт, хэрэглэгч үүсгэх, дэлгэрэнгүй харах, role үүсгэх, хэрэглэгч сонгох болон permission-ийн бүтцийг screenshot-аар тайлбарлана. Зурагт байхгүй цонх, хадгалтын үр дүн, бизнесийн дүрмийг тусад нь тэмдэглэсэн.

## Нэмж баталгаажуулах хүрээ

- **User Management** — Add Role, Set Role, Set Work Organization, засвар, нууц үг, идэвхгүй болгох цонх болон хадгалалтын үр дүн.
- **Role Management** — хадгалалтын үр дүн, засвар болон эрхийн өөрчлөлт хэзээ үйлчлэх дүрэм.
- **Business Organization** — үүсгэх маягт, хадгалалт, засвар болон төлөв өөрчлөх үйлдэл.

[Тестийн оролцогчдын лавлах](../reference/user-roles.md) нь одоо байгаа нэмэлт мэдээлэл. Үүнийг User Management / Role Management заавар эсвэл эрхийн матриц гэж үзэхгүй.
