# Жолооч оноох

## Зорилго

Хүргэлтийн даалгаврыг гүйцэтгэх жолоочийг онооно.

## Урьдчилсан нөхцөл

Хүргэлтийн даалгавар болон жолоочийн бүртгэл бэлэн байна. Тестийн дараалалд [тээврийн хэрэгсэл оноосон](assign-vehicle.md) байна.

## Цэсний зам

Web TMS → Delivery Task. Цэсний бүрэн шатлал эх сурвалжид өгөөгүй.

## Алхамууд

1. **B2CVS260922000001** хүргэлтийн даалгаврыг нээнэ.
2. **[B2C-DRV05] Мөнхөө** жолоочийг онооно.
3. Жолоочийн код, нэр, утас **88000005** эсэхийг шалгана.

    ![Хүргэлтийн даалгаварт B2C_TEST тээвэрлэгч, Toyota Vitz, 1018УБА болон Мөнхөө жолооч оноосон байдал](../assets/screenshots/tc-b2c-e2e-001/02-delivery-task-driver-assigned.png)

    **Зураг дээрх тэмдэглэгээ:** 1 — тээвэрлэгч, тээврийн хэрэгсэл, жолоочийн оноолт; 2 — даалгаврыг нийтлэх үйлдлийн хэсэг.

4. [Хүргэлтийн даалгаврыг нийтэлнэ](publish.md).

## Хүлээгдэж буй үр дүн

Хүргэлтийн даалгаварт **B2C-DRV05** жолооч оноогдсон байна.

## Анхаарах зүйл

Оноолтын цонх, хадгалах товч болон жолооч солих үйлдлийг эх сурвалжид дэлгэрүүлээгүй.
