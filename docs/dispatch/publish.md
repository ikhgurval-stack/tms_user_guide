# Хүргэлтийн даалгавар нийтлэх

## Зорилго

Оноолт хийсэн хүргэлтийн даалгаврыг жолоочийн аппликейшнд хүргэнэ.

## Урьдчилсан нөхцөл

Хүргэлтийн даалгаварт [тээврийн хэрэгсэл](assign-vehicle.md) болон [жолооч](assign-driver.md) оноосон байна.

## Цэсний зам

Web TMS → Delivery Task; нийтэлсний дараах шалгалт: Driver App → Current.

## Алхамууд

1. **B2CVS260922000001** даалгаврыг нээж, **1018УБА** тээврийн хэрэгсэл болон **B2C-DRV05** жолооч оноосон эсэхийг шалгана.
2. Хүргэлтийн даалгаврыг нийтлэх (publish) үйлдэл хийнэ.
3. Жолооч Driver App-ийн **Current** хэсгийг нээж, уг даалгавар орж ирсэн эсэхийг шалгана.
4. [Ачилт баталгаажуулах](../execution/index.md) алхамд шилжинэ.

## Хүлээгдэж буй үр дүн

Нийтэлсэн хүргэлтийн даалгавар жолоочийн **Current** хэсэгт харагдана.

## Анхаарах зүйл

Энэ тестээр даалгаврыг нийтэлсний дараа апп дээр харагдсаныг баталгаажуулсан. Нийтлэх товчны яг нэр болон уг үйлдлээс үүсэх Web төлөвийн нэрийг эх сурвалжид өгөөгүй.
