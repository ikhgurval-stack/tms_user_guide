# Үндсэн өгөгдөл бэлтгэх

## Зорилго

B2C хүргэлтийг төлөвлөхөөс өмнө захиалагч, ачилтын цэг, хүргэлтийн цэг, тээвэрлэгч, тээврийн хэрэгсэл болон жолоочийн бүртгэлийг шалгана.

## Урьдчилсан нөхцөл

Web TMS-д холбогдох бүртгэлийг харах боломжтой байна. Доорх нь TC-B2C-E2E-001 тестэд ашигласан өгөгдөл; шинэ бүртгэлд заавал ашиглах утга биш.

## Цэсний зам

Үндсэн өгөгдлийн бүртгэл үүсгэх нарийвчилсан цэсний зам тестийн эх сурвалжид өгөөгүй.

## Алхамууд

1. Захиалагч (Customer) **B2C-DEMO / BDC** бүртгэлтэй эсэхийг шалгана.
2. Ачилтын цэг (Loading Point) **[DEMO-DC01] Demo Distribution Center** бүртгэлтэй эсэхийг шалгана.
3. Хүргэлтийн хоёр цэг (Delivery Point) **[B2C-DP-031] B2C Home 031**, **[B2C-DP-032] B2C Home 032**-ыг шалгана.
4. Тээвэрлэгч (Carrier) **[B2C_TEST01] B2C_TEST**-ийг шалгана.
5. **Toyota Vitz**, улсын дугаар **1018УБА** тээврийн хэрэгслийн бүртгэлийг шалгана.
6. **[B2C-DRV05] Мөнхөө**, утас **88000005** жолоочийн бүртгэлийг шалгана.
7. Store App-аар хүлээн авалтыг шалгах бол DP-032 цэгийн **qqB2C-DP-032** хэрэглэгчийг бэлтгэнэ.

## Хүлээгдэж буй үр дүн

[Тээврийн захиалга](../transportation-order/create-order.md) болон [оноолт](../dispatch/assign-vehicle.md)-д ашиглах үндсэн өгөгдөл бүрдсэн байна.

## Анхаарах зүйл

Тестийн мэдээлэлд Store хэрэглэгчийг хүргэлтийн цэгт автоматаар эсвэл тусгай функцээр үүсгэдэг гэж тэмдэглэсэн. Үүсгэх яг аль арга, цэс, товчийг ашигласныг тодорхойлоогүй тул энд бүртгэл үүсгэх үйлдэл заагаагүй.
