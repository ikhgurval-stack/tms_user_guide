# Аппликейшнд нэвтрэх

## Зорилго

Driver App болон Store App-д тестийн оролцогчийн мэдээллээр ажиллана.

## Урьдчилсан нөхцөл

Хэрэглэгчийн нэвтрэх мэдээлэл бэлтгэгдсэн байна. Нууц үг болон нэвтрэх нарийвчилсан алхам тестийн эх сурвалжид өгөөгүй.

## Баталгаажсан мэдээлэл

- Driver App-д **[B2C-DRV05] Мөнхөө** жолоочийн даалгаврыг гүйцэтгэсэн. **88000005** нь жолоочийн утас; үүнийг нэвтрэх нэр гэж баталгаажуулаагүй.
- Store App-д **qqB2C-DP-032** хэрэглэгчээр нэвтэрч, **B2C Home 032** дэлгүүрийн хүлээн авалтыг шалгасан.

Нэвтэрсний дараа жолооч [Current хэсэг дэх даалгаврыг](../dispatch/publish.md), дэлгүүрийн хэрэглэгч [Receipt List](../execution/store-app.md)-ийг шалгана.
