# Гарын авлагын чиглүүлэг

## Гарын авлагын үндсэн хэсгүүд

- [TMS](../tms/index.md): бүлгийн тоймоос үйлдлийн заавар руу орно.
- [RPT](../reports/index.md): тайлангийн баримтжуулалтын хүрээ.
- [SYS](../sys/index.md): системийн удирдлага.
- [Mini App](../mini-app/index.md): Driver App / Store App.
- [Бусад](../other/index.md): нэр томьёо, End-to-End процесс, FAQ, Test Case, Known Issues.

Компьютер дээр дээд tab-аас хэсгээ сонгож, зүүн цэсээр дэд бүлэгт орно. Гар утсанд цэсний товчоор шаталсан navigation-ийг нээнэ. Лого эсвэл Бусад → Системийн ерөнхий танилцуулга холбоосоор [нүүр хуудас](../index.md) руу буцна.

## Батлагдсан цэсний зам

| Орчин | Цэсний зам | Зориулалт |
|---|---|---|
| Driver App | Current | Нийтэлсэн даалгаврыг харах |
| Driver App | Task List → Completed | Дууссан даалгавруудыг харах |
| Store App | Receipt List → Received | Хүлээн авсан хүргэлтийн мэдээллийг харах |
| Web TMS | Transportation Management → Transportation Evaluation | Store App-аас илгээсэн үнэлгээг шалгах |

Бусад үйлдлийн дэлгэцийн нэрийг холбогдох зааварт дурдсан. Эх сурвалжид байхгүй цэсний шатлал, товчны нэрийг нэмж оруулаагүй.
