## Батлагдсан цэсний зам

| Орчин | Цэсний зам | Зориулалт |
|---|---|---|
| Driver App | Current | Нийтэлсэн даалгаврыг харах |
| Driver App | Task List → Completed | Дууссан даалгавруудыг харах |
| Store App | Receipt List → Received | Хүлээн авсан хүргэлтийн мэдээллийг харах |
| Web TMS | Transportation Management → Transportation Evaluation | Store App-аас илгээсэн үнэлгээг шалгах |

Бусад үйлдлийн дэлгэцийн нэрийг холбогдох зааварт дурдсан. Эх сурвалжид байхгүй цэсний шатлал, товчны нэрийг нэмж оруулаагүй.
