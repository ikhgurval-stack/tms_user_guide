# Гараар төлөвлөх

## Баталгаажуулалтын хүрээ

TC-B2C-E2E-001 тестэд Intelligent Dispatch ашигласан. Гараар төлөвлөх (Manual Planning) үйлдлийг энэ тестээр баталгаажуулаагүй.

Нарийвчилсан зааврыг үйлдэл, цэс, талбар болон үр дүнг баталгаажуулсны дараа нэмнэ.

[Ухаалаг төлөвлөлтийн заавар](smart-plan.md).
