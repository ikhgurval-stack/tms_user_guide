# Гараар төлөвлөх — өмнөх тестийн хүрээ

Өмнөх [TC-B2C-E2E-001](../testing/tc-b2c-e2e-001.md)-д Intelligent Dispatch ашигласан. Manual Planning нэртэй үйлдлийг тэр тестээр баталгаажуулаагүй.

Шинэ зурагт **Quick Scheduling** нь New route, Vehicle type, Vehicle сонголттой дэлгэцээр харагдана. [Quick Scheduling-ийн зааварт](quick-scheduling.md) одоогийн Planned Route = 0, Save идэвхгүй үр дүнг тайлбарласан.

[Route Scheduling](route-scheduling.md) нь тусдаа цэс бөгөөд маршрут бүрийн машин, жолоочийн мэдээлэлтэй. Үүнийг өмнөх Manual Planning нэртэй шууд адилтгах нотолгоо байхгүй.

[Scheduling-ийн аргуудын харьцуулалт](../tms/transportation-management.md#scheduling) → [Transport Plan](overview.md).
