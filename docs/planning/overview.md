# Тээврийн төлөвлөлт

Тээврийн захиалгуудаар тээврийн төлөвлөгөө (Transportation Plan) үүсгээд, уг төлөвлөгөөнөөс хүргэлтийн даалгавар (Delivery Task) үүсгэнэ.

TC-B2C-E2E-001 тестэд [ухаалаг төлөвлөлт (Intelligent Dispatch)](smart-plan.md) ашигласан. Repository дахь Smart Plan нэртэй файлын замыг хадгалсан. [Гараар төлөвлөх](manual-plan.md) үйлдлийг энэ тестээр баталгаажуулаагүй.

Амжилттай төлөвлөсний дараа [тээврийн хэрэгсэл](../dispatch/assign-vehicle.md), [жолооч](../dispatch/assign-driver.md) оноож, [даалгаврыг нийтэлнэ](../dispatch/publish.md).
