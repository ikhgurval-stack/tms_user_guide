# Тестийн оролцогчид

Доорх хүснэгт нь тестэд гүйцэтгэсэн ажлыг тайлбарлана. Системийн эрхийн нэр, зөвшөөрлийн матриц гэж үзэхгүй.

| Оролцогч | Гүйцэтгэсэн ажил |
|---|---|
| Web TMS хэрэглэгч | Төлөвлөлт, оноолт, даалгавар нийтлэх, захиалга болон үнэлгээг шалгах |
| Жолооч: [B2C-DRV05] Мөнхөө | Driver App-аар ачилт, хүргэлт, сав буцаан татах ажиллагааг гүйцэтгэх |
| Store хэрэглэгч: qqB2C-DP-032 | B2C Home 032 цэгийн хүлээн авалтыг шалгаж, үнэлгээ илгээх |
| Зардлын баримт хянасан хэрэглэгч | Review хийж, тайлбар оруулан Approve хийх |

Web хэрэглэгчдийн ID, оноосон эрх болон хянах/батлах эрхийн ялгааг эх сурвалжид өгөөгүй.
