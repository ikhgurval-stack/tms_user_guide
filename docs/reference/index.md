## Нэр томьёо

| UI нэр | Гарын авлагад ашиглах нэр |
|---|---|
| Transportation Order | Тээврийн захиалга |
| Intelligent Dispatch | Ухаалаг төлөвлөлт |
| Transportation Plan | Тээврийн төлөвлөгөө |
| Delivery Task | Хүргэлтийн даалгавар |
| Loading Point | Ачилтын цэг |
| Delivery Point | Хүргэлтийн цэг |
| Carrier | Тээвэрлэгч |
| Pickup Registration | Буцаан татах бүртгэл |
| Pickup Order | Буцаан татах захиалга |
| Pickup Task | Буцаан татах даалгавар |
| Transport Evaluation / Transportation Evaluation | Тээврийн үнэлгээ; апп тус бүрийн UI нэрийг хадгална |
| Carrier Freight Agreement | Тээвэрлэгчийн тээврийн хөлсний гэрээ |
| Carrier Expense Bill | Тээвэрлэгчийн зардлын баримт |

Энэ тестийн Pickup нь сав буцаан татах ажиллагааг заана.
