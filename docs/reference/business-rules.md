# Тестээр баталгаажсан ажиллагаа

Энд дурдсан зүйлс нь TC-B2C-E2E-001 тестийн хүрээнд баталгаажсан. Бусад тохиргоо, хувилбарт нийтлэг үйлчлэх дүрэм гэж өргөжүүлэн тайлбарлахгүй.

| Ажиллагаа | Баталгаажсан үр дүн | Дэлгэрэнгүй |
|---|---|---|
| Даалгаврыг нийтлэх | Оноосон жолоочийн Current хэсэгт харагдсан | [Нийтлэх](../dispatch/publish.md) |
| Сав буцаан татах бүртгэл | Pickup Order автоматаар үүсэж, үндсэн хүргэлтийг үргэлжлүүлсэн | [Гүйцэтгэл](../execution/index.md) |
| Хүргэлт дуусах | Тусдаа Pickup Task автоматаар гарсан | [Гүйцэтгэл](../execution/index.md) |
| Store үнэлгээг илгээх | Web Transportation Evaluation хэсэгт орсон | [Үнэлгээ](../execution/store-app.md) |
| Гэрээний тээвэрлэгч зөрөх | “Төлбөр тооцооны гэрээ таараагүй” мэдэгдэл гарсан | [Төлбөр тооцоо](cost-settlement.md) |
| Цэгээр үнэ тооцох | 2 × 5,000 = 10,000 | [Төлбөр тооцоо](cost-settlement.md) |

Төлөвлөлт ба гүйцэтгэлийн дарааллын ялгаа, бодит явсан зай, валютын тэмдэг нь [ажиглалт болон баталгаажуулах асуудал](../troubleshooting/index.md) юм.
