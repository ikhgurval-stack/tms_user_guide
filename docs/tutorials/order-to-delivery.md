# B2C: захиалгаас төлбөр тооцоо хүртэл

## Зорилго

TC-B2C-E2E-001 тестээр баталгаажсан Order-to-Settlement урсгалыг дарааллаар нь дагана. Энэ хуудас ажлын дарааллыг нэгтгэж, үйлдлийн дэлгэрэнгүй зааварт холбоно.

## Урьдчилсан нөхцөл

Web TMS, Driver App болон Store App-д ажиллах хэрэглэгчид, тестийн үндсэн өгөгдөл бэлэн байна. Бүртгэлийн утгуудыг [үндсэн өгөгдлийн заавар](../getting-started/overview.md), баримтын дугааруудыг [тестийн бүртгэл](../testing/tc-b2c-e2e-001.md)-ээс харна.

## Хүлээгдэж буй үр дүн

Хүргэлтийн даалгавар, буцаан татах даалгавар болон буцаан татах захиалга **Completed** болно. Store App-ийн хүлээн авалт **Received** хэсэгт харагдаж, үнэлгээ Web TMS-д орсон байна. Зардлын баримт хянагдсан/батлагдсан байна.

## Анхаарах зүйл

Энэ дараалал нь тестэд дагасан урсгал. Store App-ийн үнэлгээг төлбөр тооцооны заавал биелүүлэх системийн нөхцөл гэж баталгаажуулаагүй.

[Ажиглагдсан асуудлууд](../troubleshooting/index.md) болон [нотолгооны TODO](../testing/tc-b2c-e2e-001.md)-г шалгана. Үндсэн өгөгдөл, захиалга үүсгэх нарийвчилсан үйлдэл болон амжилттай төлөвлөлтийн тохиргооны утгуудыг нэмж баталгаажуулах шаардлагатай.
