# Түгээмэл асуулт

## Энэ тестийн Pickup нь бараа буцаалт уу?

Энэ тестэд **нэг Tote Box сав буцаан татсан**. Бараа буцаах ажиллагааг баталгаажуулаагүй. [Гүйцэтгэлийн заавар](../execution/index.md).

## Сав бүртгэсний дараа хүргэлтээ үргэлжлүүлж болох уу?

Тестэд Pickup Registration нь хүргэлтийг үргэлжлүүлэхэд саад болоогүй. Бүх цэг дууссаны дараа тусдаа Pickup Task автоматаар гарсан.

## Store App-ийн үнэлгээг хаанаас шалгах вэ?

Web TMS → **Transportation Management → Transportation Evaluation** хэсгээс шалгана. [Үнэлгээний заавар](../execution/store-app.md).

## 10,000 дүнг төгрөг гэж үзэж болох уу?

Эх сурвалжид валют баталгаажаагүй. UI дээр **¥** харагдсан тул валютын харагдацын тохиргоог тусад нь шалгана. [Төлбөр тооцооны тэмдэглэл](../reference/cost-settlement.md).
