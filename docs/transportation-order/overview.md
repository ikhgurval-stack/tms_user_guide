# Тээврийн захиалга

Тээврийн захиалга (Transportation Order) нь B2C төлөвлөлтийн эхлэл болно. TC-B2C-E2E-001 тестэд хүргэлтийн хоёр цэгт хамаарах **2 захиалга** ашигласан.

[Захиалгын өгөгдлийг шалгасны](create-order.md) дараа [Intelligent Dispatch](../planning/smart-plan.md)-аар төлөвлөнө.

Захиалга шинээр үүсгэх товч, талбарын шаардлага, захиалгын ID болон төлөвийн шилжилтийг эх сурвалжид өгөөгүй. [Импортлох](import-orders.md), [засварлах](edit-order.md), [цуцлах](cancel-order.md) үйлдлийн үр дүн энэ тестээр баталгаажаагүй.
