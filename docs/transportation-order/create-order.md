# Тээврийн захиалгын өгөгдлийг шалгах

## Зорилго

B2C төлөвлөлтөд ашиглах захиалга болон хүргэлтийн цэгүүдийг шалгана.

## Урьдчилсан нөхцөл

[Үндсэн өгөгдөл](../getting-started/overview.md) бүрдсэн байна.

## Цэсний зам

Web TMS-ийн тээврийн захиалга (Transportation Order) хэсэг. Цэсний бүрэн шатлал эх сурвалжид өгөөгүй.

## Алхамууд

1. **B2C-DEMO / BDC** захиалагчийн тестэд ашиглах хоёр захиалгыг шалгана.
2. Ачилтын цэг **[DEMO-DC01] Demo Distribution Center** эсэхийг шалгана.
3. Хүргэлтийн цэгүүд **B2C-DP-031**, **B2C-DP-032** эсэхийг шалгана.
4. Хоёр захиалгыг [Intelligent Dispatch төлөвлөлтөд](../planning/smart-plan.md) ашиглана.

## Хүлээгдэж буй үр дүн

Төлөвлөлтөд ашиглах **2 захиалга / 2 хүргэлтийн цэг** тодорхой болсон байна.

## Анхаарах зүйл

Энэ хуудас одоо байгаа `create-order.md` замыг хадгалсан. Захиалга үүсгэх дэлгэцийн талбар, товч, заавал бөглөх утгууд өгөгдөөгүй тул шинэ захиалга үүсгэх нарийвчилсан заавар оруулаагүй.
