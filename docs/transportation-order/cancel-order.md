# Тээврийн захиалга цуцлах

## Хэзээ ашиглах вэ?

Цуцлах шаардлагатай захиалгын дугаар, харилцагч, цэг болон холбоотой Delivery Task-уудыг эхлээд [дэлгэрэнгүй](overview.md#transport-order-detail)-гээс нягтална.

## Боломжит үйлдэл

Transport Order жагсаалтад **Batch cancel** харагдана. Энэ нь захиалгын бөөн цуцлалтын боломж. Delivery Task-ийн **Cancel**, **Cancel task and order**-оос өөр дэлгэцийн үйлдэл.

## Баталгаажуулалтын хүрээ

Цуцлах баталгаажуулалт, зөвшөөрөх төлөв, дараах үр дүн одоогийн тестээр баталгаажаагүй. Order Detail-д **Cancelled** Delivery Task харагдсан нь Transport Order өөрөө цуцлагдсан гэсэн үг биш.

## Дараагийн алхам

[Захиалгын төлөв](order-status.md), [Delivery Task-ийн нийтлэх ба нэмэлт ажиллагаа](../dispatch/publish.md)-г харна.
