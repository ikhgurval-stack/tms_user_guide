# Тээврийн захиалгын төлөв

## Баталгаажуулалтын хүрээ

TC-B2C-E2E-001-ийн эх сурвалжид тээврийн захиалгын төлөвийн нэр, шилжилтийг өгөөгүй. Delivery Task болон Pickup Order-ийн төлөвийг Transportation Order-ийн төлөв гэж ашиглахгүй.

Нарийвчилсан зааврыг үйлдэл, цэс, талбар болон үр дүнг баталгаажуулсны дараа нэмнэ.

[Баталгаажсан төлөвийн лавлах](../reference/status-reference.md).
