# Тээврийн захиалга импортлох

## Хэзээ ашиглах вэ?

Transport Order жагсаалтын **Import** товчоор захиалга файлаас оруулах боломж харагдана. Байршлыг [жагсаалтын зураг](overview.md)-аас харна.

## Эхлэхийн өмнө

Импортын зөв загвар, файлын төрөл, шаардлагатай багануудыг системийн хариуцагчаас тодруулна. Одоогийн зурагт импортын цонх, загвар болон алдааны тайлбар байхгүй.

## Баталгаажуулалтын хүрээ

Шинэ зурагт Import товч байгаа нь батлагдсан. Файл сонгох, багана тааруулах, амжилттай импортлох болон давхардсан захиалга боловсруулах үр дүн одоогийн тестээр баталгаажаагүй.

## Дараагийн алхам

Нэг захиалга гараар бэлтгэх бол [New Transport Order](create-order.md)-ыг ашиглана. Импорт хийсэн бол [жагсаалт ба дэлгэрэнгүй](overview.md)-д дугаар, цэг, хэмжээ, огноогоор шалгана.
