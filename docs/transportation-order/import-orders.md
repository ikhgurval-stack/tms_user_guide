# Тээврийн захиалга импортлох

## Баталгаажуулалтын хүрээ

TC-B2C-E2E-001-ийн эх сурвалжид импортын үйлдэл, файлын загвар, баганын шаардлага болон үр дүн өгөөгүй.

Нарийвчилсан зааврыг үйлдэл, цэс, талбар болон үр дүнг баталгаажуулсны дараа нэмнэ.
