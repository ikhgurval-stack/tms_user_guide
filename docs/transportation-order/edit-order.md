# Тээврийн захиалга засварлах

## Хэзээ ашиглах вэ?

Захиалгын мэдээлэл зөрсөн үед эхлээд [дэлгэрэнгүй](overview.md#transport-order-detail)-г нээж харилцагч, цэгүүд, хэмжээ, огноо болон холбоотой Delivery Task-уудыг шалгана.

## Боломжит үйлдэл

Transport Order жагсаалтын **Batch modification** товч нь бөөнөөр засварлах боломжийг харуулна. **Batch set review status** нь хяналтын төлөв тохируулах тусдаа боломж.

## Баталгаажуулалтын хүрээ

Засварлах цонх, зөвшөөрөх төлөв, өөрчилж болох талбар, хадгалалтын үр дүн одоогийн тестээр баталгаажаагүй. Аль хэдийн төлөвлөсөн захиалгыг өөрчлөхөд төлөвлөгөө, даалгавар хэрхэн шинэчлэгдэхийг энэ зургаас дүгнэхгүй.
